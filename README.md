# Maplas — Country Guessing Game

Maplas is a browser-based country trivia game. The idea behind the project was simple: collect as much publicly available information as possible about every country in the world such as capitals, flags, anthems, borders, flag colours, country outlines, alcohol consumption data, and more we combined it all into a fun and replayable guessing game that tests your geography and general knowledge.

Each round, a mystery country is chosen at random. You are given clues one by one and have to figure out which country it is before you run out of guesses. The clues are pulled from the real-world data scraped during setup, meaning every fact you see in the game is genuine public information. The more knowledge you have on all the countries, the better your chances.

The project was built in two parts: a **scraping pipeline** that gathers and cleans all country data from the web, and a **web app** that uses that data to power the game in your browser.


## Data Setup (Running the Scrapers)

The game requires a local dataset of country information generated by the scraping pipeline. To generate the data:

```bash
cd collecting_info
python main.py
```

This runs all scrapers in the correct order:

| Step | Script | What it collects |
|------|--------|-----------------|
| 1 | `country_collection.py` | Country list from Wikipedia |
| 2 | `scrape_country_info.py` | Capitals, flags, languages, religion, area, population, GDP, currency, time zone, calling code |
| 3 | `data_cleaner.py` | Cleans and formats the dataset, adds rankings |
| 4 | `Alcohol_consumption_ranked_scraper.py` | Alcohol consumption per capita |
| 5 | `Bordering_Countries_Scraper.py` | Border lengths, number of borders, neighbours |
| 6 | `Country_flag_colour_scraper.py` | Flag colour data |
| 7 | `country_outline_scraper.py` | Country outline images (PNG) |

> This process may take several minutes due to the number of HTTP requests and image generation.

You can also run individual scrapers:

```bash
cd collecting_info
python -c "from scrapers.Alcohol_consumption_ranked_scraper import main; main()"
```

## How to Play

Open `collecting_info/countrydle.html` in your browser to play the game.

1. Each round a **mystery country** is selected at random.
2. You receive an initial clue and have to guess which country it is.
3. With each wrong guess, a **new clue** is revealed (e.g. flag colours, outline, anthem, borders).
4. You have a limited number of guesses — try to keep your **streak** alive!
